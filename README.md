# AI Image Forgery and Synthetic Image Detection System

## Project Overview

The **AI Image Forgery and Synthetic Image Detection System** is a deep learning-based application designed to identify AI-generated images and detect traditional image manipulation.

The system uses two independent EfficientNetB0 models:

1. **AI-Generated Image Detection:** Uses the CIFAKE dataset to classify images as REAL or AI-GENERATED.
2. **Image Forgery Detection:** Uses the CASIA V2.0 dataset to classify images as AUTHENTIC or TAMPERED.

A Streamlit-based web application provides an interface where users can upload an image and obtain the detection result.

## System Architecture

The application uses two detection models:

- The CIFAKE model checks whether an image is AI-generated.
- The CASIA V2.0 model checks whether an image contains traditional manipulation.

Both models analyze the uploaded image. The application then applies a decision rule to produce one of three final results:

- AI-GENERATED IMAGE
- FORGED / TAMPERED IMAGE
- AUTHENTIC / REAL IMAGE

## Model Information

| Model | Dataset | Classification |
|---|---|---|
| EfficientNetB0 | CIFAKE | REAL / AI-GENERATED |
| EfficientNetB0 | CASIA V2.0 | AUTHENTIC / TAMPERED |

Both models use transfer learning with ImageNet-pretrained EfficientNetB0.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/vashu114/Image-forgery-and-synthetic-image-Detection-system.git
```

### 2. Open the Project Directory

```bash
cd Image-forgery-and-synthetic-image-Detection-system
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Add Trained Model Files

Download the trained model files and place them in the appropriate location:

- `cifake_efficientnetb0_best.keras`
- `casia_improved_stage1_best.keras`

Update the model paths in `app.py` according to your local setup.

### 5. Run the Application

```bash
streamlit run app/app.py
```

## Model Performance

The CIFAKE EfficientNetB0 model achieved the following test results:

| Metric | Result |
|---|---:|
| Accuracy | 94.17% |
| Precision | 94.46% |
| Recall | 93.84% |

*These results represent evaluation on the CIFAKE test dataset.*

## Important Note

The trained model weight files are not included in this repository because of their file size. They need to be downloaded separately and made accessible to the application.
